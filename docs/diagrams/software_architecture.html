기록
수집 경로가 파생 처리에 묶이지 않는다 — ingest 는 저장을 트랜잭션으로 확정한 뒤 경보 · 송출 · 노출량 · 측위 · 복귀 콜백을 트랜잭션 밖에서 부른다. 대시보드 한 대가 응답하지 않아도 센서 수집이 멈추지 않고, 콜백 하나가 실패해도 나머지와 다음 샘플이 그대로 진행된다.

안전 경보와 연구 지표가 스토어 수준에서 갈라져 있다 — 같은 딕셔너리에 두면 경보 배너 · 요약 집계 · 알림이 연구 지표까지 세게 되고, 검증되지 않은 참고값이 산업안전 판단 근거로 화면에 올라간다. 두 타입 사이의 변환 함수를 만들지 않는 것이 이 분리를 유지하는 방법이다.

판정 상태 7종 — 판단하지 못한 것을 정상이라 하지 않는다
판단됨 : 정상 패턴 · 이상 후보 · 이상
판단 불가 : 모델 미준비 · 데이터 부족 · 데이터 노후 · 특징 불일치  — 점수는 0 이 아니라 빈 값으로 남긴다
밀폐공간에서 센서가 멈췄는데 화면이 “정상”으로 남는 것은 미검출보다 위험하다. 데이터 부족 · 데이터 노후 · 특징 불일치를 정상 상태로 변환하는 경로를 코드에 두지 않으며, 자동화 검사가 이 분리를 회귀 검증한다.

## 1. 프로젝트 명

IoT 센서 시계열 분석 및 3D 디지털 트윈 기반 조선소 밀폐공간 모니터링 시스템

## 2. 프로젝트 개요

조선소 밀폐공간(탱크 내부, 이중저 구획 등) 작업 시 발생할 수 있는 유해가스 누출, 산소 결핍, 낙상 위험을 실시간으로 감지하고 관리자 및 작업자에게 즉각 경보를 제공하는 IoT 기반 안전 모니터링 시스템이다.

센서 노드가 수집한 시계열 데이터는 MQTT를 통해 서버로 전송되고, 관리자는 웹 대시보드에서 실시간 환경 현황 및 3D 디지털 트윈 시각화를 통해 밀폐공간 내부 상황을 확인한다.

## 3. 대상 사용자

| 사용자 유형 | 설명 | 주요 과업 |
|-------------|------|-----------|
| 안전 관리자 | 육상 또는 현장 외부에서 대시보드를 모니터링 | 실시간 수치 확인, 경보 수신, 이력 조회 |
| 현장 작업자 | 밀폐공간 내부에서 작업 | 웨어러블 착용, 진동 알림 수신 |
| 작업 감독자 | 현장 외부에서 작업 감독 | 경보 수신, 대피 지시 |

## 4. 시스템 구성

| 노드 | 수량 | 메인보드 | 주요 기능 |
|------|------|----------|-----------|
| 센서 노드 (Full-Spec) | 4 | ESP32 DevKitC V4 | CO₂/CO/H₂S/가스저항/온습도 + UWB Anchor |
| 웨어러블 노드 | 1 | ESP32 DevKitC V4 | O₂/낙상 감지 + UWB Tag + 진동 알림 |

> UWB 위치 측위: 센서 노드 4개(앵커) + 웨어러블 1개(태그), DS-TWR 방식

## 5. MVP 목표 흐름

```
센서 노드 전원 ON
→ 가스·온습도·O₂ 데이터 실시간 수집 및 MQTT 전송
→ 서버 수신·저장 및 임계값 비교
→ 위험 등급 판정 및 경보 발령
→ 웨어러블 진동 알림 전달
→ 대시보드 실시간 시각화 및 3D 디지털 트윈 표시
→ 시계열 데이터 조회 및 이벤트 로그 확인
```

## 6. 기술 스택

| 계층 | 기술 |
|------|------|
| 펌웨어 | Arduino Framework (ESP32), PlatformIO |
| 통신 | MQTT (Mosquitto), UWB DS-TWR (DWM1000) |
| 백엔드 | FastAPI (Python) |
| DB | TimescaleDB |
| 실시간 전송 | WebSocket |
| 프론트엔드 | React 19 + TypeScript |
| 3D | React Three Fiber + Three.js |
| 상태 관리 | Zustand |
| 차트 | Recharts |

## 8. 면책 범위

본 시스템은 **작업자 안전을 보조하는 모니터링·경보 도구**이다. 최종 대피 판단 및 작업 중지 결정은 현장 관리자에게 있으며, 본 시스템의 경보가 공식 산업안전보건 기준을 대체하지 않는다.

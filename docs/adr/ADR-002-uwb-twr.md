# ADR-002: UWB 측위 방식 DS-TWR 확정

| 항목 | 내용 |
|------|------|
| 상태 | Accepted |
| 결정일 | 2026-07-13 |
| 결정자 | 팀 합의 |

## 배경

초기 문서에서 UWB 측위 방식을 "TDoA 또는 TWR"로 명시했다. 그러나 TWR와 TDoA는 단순한 알고리즘 옵션이 아니라 통신 및 동기화 구조가 근본적으로 다르다. TDoA는 앵커 간 정밀 동기화 설계가 추가로 필요하며, Qorvo(DW1000 제조사)도 TWR 구현, 안테나 지연 보정, NLOS 오차 및 TDoA 앵커 동기화를 별도 설계 항목으로 다룬다.

## 결정

4 Anchor + 1 Tag, DS-TWR(Double-Sided Two-Way Ranging) 기반 2D 측위로 확정한다. TDoA는 MVP 이후 단계로 미룬다.

## 대안

| 대안 | 결과 | 이유 |
|------|------|------|
| TWR (DS-TWR) | 채택 | 앵커 동기화 불필요, 구현 상대적 단순, 성숙한 라이브러리 존재 |
| TDoA | 기각 | 앵커 간 무선 동기화 필요, 구현 복잡도 높음, MVP 일정 내 구현 불확실 |

## 결과

**긍정:**
- 구현 단순 (앵커 동기화 불필요)
- Qorvo/Decawave 예제 코드 활용 가능
- 소규모 실내 환경에 적합

**부정:**
- Tag당 측정 시간이 TDoA보다 김 (4개 앵커 순차 측정)
- 대역폭 사용량 증가 (각 앵커와 개별 통신)
- 실내 소규모 환경(본 프로젝트)에서는 문제 없음

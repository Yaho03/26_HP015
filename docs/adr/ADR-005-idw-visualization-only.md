# ADR-005: IDW 공간 보간 시각화 전용 사용

| 항목 | 내용 |
|------|------|
| 상태 | Accepted |
| 결정일 | 2026-07-13 |
| 결정자 | 팀 합의 |

## 배경

ARCHITECTURE에서 4개 센서로 3D 공간 전체의 가스 농도를 IDW로 추정하는 설계가 있었다. 그러나 IDW는 물리적 가스 확산 모델이 아니며, 환기 방향, 가스 밀도, 장애물, 열 대류, 출입구, 누출원 방향, 시간에 따른 이동을 반영하지 않는다. 4개 센서만으로 3D 분포를 검증하기 어려우며, IDW 추정값을 경보 판정에 사용할 경우 안전 위험이 발생할 수 있다.

## 결정

IDW는 시각화 전용으로만 사용한다. 안전 경보는 실제 센서 측정값으로만 판정한다. 화면에 "Estimated concentration surface based on IDW interpolation" 레이블을 필수로 표시한다.

## 대안

| 대안 | 결과 | 이유 |
|------|------|------|
| IDW 시각화 전용 | 채택 | 구현 단순, 안전 위험 없음, 역할 명확 |
| IDW 경보 사용 | 기각 | 안전 위험 (검증되지 않은 추정값으로 경보 판정), 4개 센서 한계 |
| 물리적 확산 모델 (CFD) | 기각 | 구현 복잡, 계산 비용 높음, MVP 범위 초과 |
| RBF / Kriging | 향후 검토 | IDW 정확도 불충분 시 비교 검증용 (MAY) |

## 결과

**긍정:**
- 안전성 확보 (경보는 실측값 기반)
- 명확한 역할 분리 (측정값 = 경보, 추정값 = 시각화)
- 구현 단순

**부정:**
- 공간 보간 정확도 제한 (Leave-One-Out 실험으로 검증 필요)
- 사용자에게 추정값임을 명확히 전달해야 함

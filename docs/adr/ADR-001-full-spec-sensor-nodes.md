# ADR-001: 센서 노드 4개 Full-Spec 통일

| 항목 | 내용 |
|------|------|
| 상태 | Accepted |
| 결정일 | 2026-07-13 |
| 결정자 | 팀 합의 |

## 배경

초기 PRD는 메인 가스 센서 노드 1개(풀스펙)와 서브 센서 노드 3개(CO₂, 온습도 only) 구성을 제안했다. 그러나 부품 구매 시 쿠팡 실결가를 비교한 결과, 풀스펙 4개와 혼합 구성 간 73,800원 차이만 발생했다. 서브 노드의 측정 항목 제한이 실험 검증과 IDW 공간 보간 정확도에 제약이 되었다.

## 결정

4개 노드 모두 동일한 Full-Spec 구성으로 통일한다.

각 노드 구성: CO₂(MH-Z19B), CO(MQ-7), H₂S(MQ-136), 가연성 가스(MQ-2), 온도/습도/가스저항(BME680), UWB Anchor(DWM1000 BU01).

## 대안

| 대안 | 결과 | 이유 |
|------|------|------|
| 메인 1 + 서브 3 | 기각 | 비용 절감 미미 (73,800원), 실험 검증 제약, IDW 보간 정확도 저하 |
| Full-Spec 4 | 채택 | 약간의 비용 증가 but 모든 노드에서 동일한 측정 항목 확보, IDW 보간 정확도 향상, 유지보수 단순화 |

## 결과

**긍정:**
- 모든 위치에서 동일한 가스 프로파일 확보
- 예비 부품 호환성 (모든 노드 동일 구성)
- 펌웨어 단일화 (노드별 펌웨어 분기 불필요)
- IDW 공간 보간 시 4개점 모두 동일한 측정 항목

**부정:**
- 총비용 약 73,800원 증가
- 서브 노드 전력 소비 증가 (MQ 센서 히터 추가)

## 주요 설계 결정 사항

1. **센서 노드 4개 동일 풀스펙 통일** (ADR-001)
   - 메인 1 + 서브 3 간소화 방식 검토 -> 쿠팡 실결제가 비교 시 동일 구성 4개와 73,800원 차이
   - 4개 노드 모두 동일 풀스펙으로 확정

2. **산소 센서 SEN0322 웨어러블 추가**
   - CO₂ 역연산 방식 폐기 -> 실현장에서 CO₂와 O₂ 결핍이 항상 반비례하지 않음
   - 작업자 착용 웨어러블 노드에 실제 산소 센서 장착

3. **DWM1000 BU01 직접 사용 (쿠팡 구매)**
   - UWB 위치센서 메인칩, 직접 납땜 필요
   - 48,200원 x 5개 = 241,000원

4. **MQ 센서 전원 VIN 핀 우회**
   - MQ 3종 + MH-Z19B 합산 ~600mA -> VIN 핀 허용치 초과
   - USB 전원에서 직접 분기하여 5V 레일에 공급

5. **외부 ADC(ADS1115) 사용**
   - ESP32 내장 ADC2는 WiFi 활성 시 사용 불가
   - 16-bit 정밀 ADC로 MQ 센서 아날로그값 수집

6. **분압 회로 설계 수정**
   - 이전: R1=10kΩ, R2=20kΩ -> Vout=3.33V (ADS1115 절대 최대치 근접)
   - 수정: R1=20kΩ, R2=10kΩ -> Vout=1.67V (안전 여유 확보)

## 2구간 — 전원부 (단계별 구매)

> 테스트 없이 미리 사는 것은 낭비 → 단계별 구매(phased purchasing) 방침.
> 1단계로 먼저 돌려보고, 전원 부족 증상이 확인되면 2단계를 발주한다.

### 1단계 — 일단 이것만 (충전기로 ESP32 직결)

| 부품 | 수량 | 단가(원) | 소계(원) | 역할 |
|------|------|---------|---------|------|
| 충전기 5V 2A 이상 (C/5핀) | 5 | - | - | 각 노드 ESP32 보드 USB 포트에 직접 연결 (핸드폰 충전기 가능) |
| USB 케이블 (C/5핀) | 5 | - | - | 충전기 - ESP32 연결 |

> ESP32 보드 USB 포트가 C타입인지 마이크로 5핀인지 실물 입고 후 확인 필요.
> (정품 DevKitC V4는 마이크로 5핀이나, 호환 보드는 C타입인 경우가 있음)

### 2단계 — 문제 발생 시 추가 발주

**발주 트리거 (아래 증상 확인 시):**
- ESP32가 자꾸 재부팅됨 (특히 MQ 센서 예열 중 리셋 → 전원 부족 확정)
- 센서 값이 이상하게 튐
- 보드가 뜨거워짐

| 부품 | 수량 | 단가(원) | 소계(원) | 역할 |
|------|------|---------|---------|------|
| 5V 3A DC 어댑터 + 배럴잭 커넥터 (5.5x2.1mm) | 4 | - | - | 브레드보드 5V 레일 직접 공급 (충전기보다 강한 전원) |
| MP1584 벅컨버터 (5V→3.3V) | 5 | - | - | DWM1000 전용 3.3V 공급 (AMS1117 부하 분산, 개당 2천원쯤) |
| 1000uF 전해 커패시터 | 5 | - | - | 브라운아웃 방지 (WiFi/UWB 피크 전류 버퍼) |

**2단계 권장 배선** — 5V를 보드 USB로 넣지 말고, 외부 5V 3A를 브레드보드 레일에 직접 공급하고 DevKitC 5V(VIN)핀으로 역급전:

```
5V 3A 어댑터 ─┬─ 브레드보드 5V 레일 ─ MQ×3, MH-Z19B
              └─ DevKitC 5V(VIN)핀 ─ 내장 AMS1117 → ESP32

DWM1000 ─ MP1584 벅컨버터 3.3V (DevKitC 3.3V핀 병목 회피)
```

> 이렇게 해도 DevKitC 3.3V핀에서 DWM1000을 뽑으면 병목이 남으므로,
> DWM1000은 MP1584 별도 3.3V에서 공급하는 것이 안전하다.

> **공통 접지(GND) 필수**: 어댑터 5V 레일, MP1584 3.3V 출력, ESP32 보드의
> GND를 모두 하나로 묶어야 한다. 접지가 분리되면 센서 값 튐, 통신 불안정,
> 최악의 경우 소자 손상이 발생한다.

### 시연 단계 — 웨어러블 이동 전원

> 웨어러블 노드는 작업자가 착용하고 이동하므로 충전기/어댑터 유선 급전으로는
> 시연이 불가능하다. 개발 단계는 1단계 충전기로 충분하나, 최종 평가·시연 전에
> 이동형 전원이 필요하다. (추후 지원 요청 예정)

| 부품 | 수량 | 단가(원) | 소계(원) | 역할 |
|------|------|---------|---------|------|
| 5V 소형 보조배터리 (1A 이상) | 1 | - | - | 웨어러블 노드 이동 전원 (작업자 착용) |
| USB 케이블 (C/5핀, 짧은 것) | 1 | - | - | 보조배터리 - 웨어러블 ESP32 연결 |

### 전원 레일 부하 분석 (2단계 근거)

| 레일 | 부하 | 합산 |
|------|------|------|
| 5V 레일 | MQ-2/7/136 히터 각 ~150mA + MH-Z19B ~150mA | ~620mA |
| 3.3V 레일 | ESP32 WiFi 피크 ~500mA + DWM1000 ~150mA | ~650mA |

> DevKitC 내장 AMS1117 레귤레이터는 800mA 한계로, 3.3V 레일 650mA 부하 시
> 발열 및 전압강하(브라운아웃) 위험이 있다.
> - **5V 3A DC 어댑터**: 5V 레일을 보드 외부에서 직접 공급
> - **MP1584 벅컨버터**: DWM1000 3.3V를 별도 공급하여 AMS1117 부하 분산
> - **1000uF 전해 커패시터**: WiFi/UWB 동시 피크 시 순간 전압강하 흡수
>
> 1차 구매분으로 실측 후 필요 시 발주한다.

## 주요 설계 결정 사항

1. **센서 노드 4개 동일 풀스펙 통일** (ADR-001)
   - 메인 1 + 서브 3 간소화 방식 검토 -> 쿠팡 실결제가 비교 시 동일 구성 4개와 73,800원 차이
   - 4개 노드 모두 동일 풀스펙으로 확정

2. **산소 센서 SEN0322 웨어러블 추가**
   - CO₂ 역연산 방식 폐기 -> 실현장에서 CO₂와 O₂ 결핍이 항상 반비례하지 않음
   - 작업자 착용 웨어러블 노드에 실제 산소 센서 장착

3. **DWM1000 BU01 직접 사용 (쿠팡 구매)**
   - UWB 위치센서 메인칩, 직접 납땜 필요
   - 48,200원 x 5개 = 241,000원

4. **MQ 센서 전원 VIN 핀 우회**
   - MQ 3종 + MH-Z19B 합산 ~600mA -> VIN 핀 허용치 초과
   - USB 전원에서 직접 분기하여 5V 레일에 공급

5. **외부 ADC(ADS1115) 사용**
   - ESP32 내장 ADC2는 WiFi 활성 시 사용 불가
   - 16-bit 정밀 ADC로 MQ 센서 아날로그값 수집

6. **분압 회로 설계 수정**
   - 이전: R1=10kΩ, R2=20kΩ -> Vout=3.33V (ADS1115 절대 최대치 근접)
   - 수정: R1=20kΩ, R2=10kΩ -> Vout=1.67V (안전 여유 확보)

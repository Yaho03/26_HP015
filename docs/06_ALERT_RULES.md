| 항목 | 내용 |
|------|------|
| 문서명 | 경보 판정 규칙서 |
| 버전 | v1.0 |
| 상태 | 확정 |
| 최종 수정일 | 2026-07-13 |

---

## 1. 개요

본 문서는 센서 측정값을 기반으로 위험 등급을 판정하고 경보를 발령/해제하는 규칙을 정의한다.

### 핵심 원칙

1. **경보는 실제 센서 측정값으로만 판정한다.** IDW 공간 보간 추정값은 경보에 사용하지 않는다. (ADR-005)
2. **Hysteresis를 적용한다.** 경보 발생과 해제 기준을 분리하여 플리커링을 방지한다.
3. **O₂ 센서 응답 시간을 별도 관리한다.** SEN0322 응답 시간(최대 15초)으로 인해 O₂ 경보는 전체 3초 목표에서 제외한다.
4. **임계값은 하드코딩하지 않는다.** DB 또는 설정 파일에서 관리한다.

---

## 2. 위험 등급 정의

| 등급 | 식별자 | 색상 | 의미 |
|------|--------|------|------|
| 정상 | `normal` | 초록 | 모든 측정값이 정상 범위 |
| Level 1 | `level1_caution` | 노랑 | 주의. 모니터링 강화 권장 |
| Level 2 | `level2_warning` | 주황 | 경고. 웨어러블 진동 알림 작동 |
| Level 3 | `level3_critical` | 빨강 | 위험. 대피 권장. 대시보드 팝업 + 사이렌 |

## 3. 가스 농도 임계값

### 3.1 교정 완료 센서 임계값

| 항목 | 정상 | Level 1 | Level 2 | Level 3 | 단위 |
|------|------|---------|---------|---------|------|
| CO₂ (MH-Z19B) | < 1,000 | 1,000 - 2,000 | 2,000 - 5,000 | >= 5,000 | ppm |
| CO (MQ-7, 교정 후) | < 25 | 25 - 50 | 50 - 200 | >= 200 | ppm |
| H₂S (MQ-136, 교정 후) | < 1 | 1 - 5 | 5 - 10 | >= 10 | ppm |
| 온도 (BME680) | < 35 | 35 - 38 | 38 - 40 | >= 40 | °C |
| O₂ (SEN0322) | 19.5 - 23.5 | 18.0 - 19.5 | 16.0 - 18.0 | < 16.0 또는 > 23.5 | % |

### 3.2 교정 전 센서 처리

MQ-7, MQ-136, MQ-2 센서는 교정 완료 전까지 임계값 기반 경보에서 제외한다.

- 교정 전: raw ADC 값, voltage, Rs/R0 모니터링만 수행
- 교정 완료 후: estimated_ppm 기반 임계값 경보 활성화
- BME680 가스 저항 (gas_resistance_ohm): 경보 판정에 사용하지 않고 추세 모니터링만 수행

### 3.3 BME680 IAQ 지수 참고 기준

> 아래 기준은 참고용이며, BSEC 라이브러리의 iaq_accuracy가 2 이상일 때만 유효하다.

| IAQ | 범위 | 공기질 |
|-----|------|--------|
| 0-50 | 우수 | 청결한 공기 |
| 51-100 | 보통 | 대부분의 실내 환경 |
| 101-150 | 다소 불량 | 환기 권장 |
| 151-200 | 불량 | 환기 필요 |
| 201+ | 매우 불량 | 오염 의심 |

## 4. Hysteresis 규칙

### 4.1 경보 발생 조건

```
Warning (Level 1 발생):
  metric >= threshold_level1 이 3회 연속 확인될 때

Warning (Level 2 승격):
  metric >= threshold_level2 이 3회 연속 확인될 때

Warning (Level 3 승격):
  metric >= threshold_level3 이 1회 확인될 때 (즉시)
```

### 4.2 경보 해제 조건

```
Recovery:
  metric <= threshold_current_level - hysteresis 이 5회 연속 확인될 때
```

### 4.3 Hysteresis 값

| 항목 | Hysteresis |
|------|------------|
| CO₂ | 100 ppm |
| CO | 5 ppm |
| H₂S | 0.5 ppm |
| 온도 | 1 °C |
| O₂ | 0.5 % |

### 4.4 예시: CO₂ 경보 시나리오

```
시간 1: CO2 = 2,100 ppm → Level 2 (3회 연속 카운트 시작)
시간 2: CO2 = 2,050 ppm → Level 2 (2회째)
시간 3: CO2 = 2,200 ppm → Level 2 (3회째) → 경보 발령
시간 4: CO2 = 1,950 ppm → 해제 조건 확인 (threshold 2,000 - hysteresis 100 = 1,900 초과)
시간 5: CO2 = 1,850 ppm → 해제 조건 1회 (<= 1,900)
시간 6~9: CO2 <= 1,900 유지 → 해제 조건 5회 달성 → 경보 해제
```

## 5. 낙상 감지 규칙

### 5.1 감지 조건

```
단계 1: 합성 가속도 벡터 |a| >= 2.5g 감지 (충격 감지)
단계 2: 1초 이내 |a| 변화량이 임계값 초과 (급감속)
단계 3: 이후 1초 이상 |a|가 정적 상태 (0.9g ~ 1.1g 범위) 지속
→ 낙상으로 판정
```

### 5.2 경보 발령

- 낙상 판정 시 **즉시 Level 3 경보** 발령
- 3회 연속 조건 없이 1회 판정으로 즉시 발령

### 5.3 오감지 처리

- **MAY**: 작업자가 오감지 취소 버튼을 눌러 경보를 해제할 수 있다
- 취소된 낙상 경보는 이벤트 로그에 `false_positive` 태그로 기록된다

---

## 6. O₂ 경보 특별 규칙

### 6.1 응답 시간 고려

SEN0322 O₂ 센서의 공식 응답 시간은 최대 15초이다.

- O₂ 경보는 전체 경보 3초 목표(Latency)에서 **제외**한다
- O₂ 데이터 발행 주기는 5초이므로, 경보 발령까지 최대 5초 + 백엔드 처리 시간이 소요될 수 있다
- 대시보드에 O₂ 경보 지연 가능성을 명시한다

### 6.2 단독 임계값 경보

MVP에서는 O₂ 단독 임계값 경보만 적용한다.

- O₂ < 19.5% → Level 1
- O₂ < 18.0% → Level 2
- O₂ < 16.0% → Level 3 (즉시)

## 7. 위험 구역 진입 경보

### 7.1 위험 구역 정의

- Level 2 이상 경보가 발령된 센서 노드 반경 2m 이내
- 디지털 트윈 상에서 해당 영역을 색상으로 표시

### 7.2 진입 감지

- 웨어러블 노드의 UWB 위치가 위험 구역 경계 내로 진입할 때 추가 경보 발령
- 위험 구역 진입 경보는 Level 2로 발령
- 위험 구역 이탈 시 자동 해제

## 8. 경보 알고리즘 단계

### 8.1 1단계: 임계값 기반 (MUST)

```
입력: 센서 측정값 (1초 주기)
처리:
  1. 임계값 비교
  2. 3회 연속 확인 (Level 1, 2) 또는 1회 확인 (Level 3)
  3. Hysteresis 기반 해제 (5회 연속)
출력: 경보 상태 (active / resolved)
```

### 8.2 2단계: 추세 기반 (SHOULD)

```
입력: 최근 N개 측정값
처리:
  1. 이동 평균 (window: 30초)
  2. 선형 회귀 기울기 계산
  3. EWMA (Exponentially Weighted Moving Average)
출력: 상승 추세 표시 (대시보드에 경고 배지)
```

> 추세 경고는 독립적인 경보를 발령하지 않고, 대시보드에 시각적 표시만 제공한다.

### 8.3 3단계: LSTM 예측 (MAY / Research Track)

```
입력: 과거 60초 시계열 데이터
처리:
  1. LSTM 모델로 5분 후 농도 예측
  2. 예측값이 위험 임계값 도달 예상 시 선제 경고
출력: 예측 기반 선제 경고
```

> LSTM은 충분한 실험 데이터가 확보된 후 별도 실험으로 평가한다. MVP의 MUST가 아니다.
> 학습 데이터 규모, 누출 시나리오 종류, Train/Validation/Test 분할 기준이 정의되기 전까지 모델 구조를 확정하지 않는다.

## 9. 복합 위험 점수 (참고 지표)

> 복합 위험 점수는 **실험 검증 전까지 참고 지표로만 사용**한다. 안전 경보의 단독 근거로 사용하지 않는다.

### 공식

```
Total Risk Score = (S_O2 * 0.35) + (S_Gas * 0.30) + (S_Env * 0.10) + (S_Worker * 0.25)
```

| 변수 | 설명 |
|------|------|
| S_O2 | 산소 농도 감점 점수 (정상 20.9% 기준 이탈 시 감점) |
| S_Gas | 유해가스 복합 지수 (CO, H2S, VOC 정규화 가중합) |
| S_Env | BME680 기반 온·습도 열지수 점수 |
| S_Worker | MPU-6050 및 낙상 이상 징후 매핑 점수 |

### 등급 매핑 (참고)

| 점수 | 등급 |
|------|------|
| < 40 | SAFE |
| 40 - 59 | CAUTION |
| 60 - 79 | WARNING |
| >= 80 | CRITICAL |

> 위 가중치(0.35/0.30/0.10/0.25)와 컷오프(40/60/80)는 검증 근거가 없다. 실험 데이터 누적 후 조정한다.

## 10. 경보 발행 규칙

### 10.1 발행 주체

| 경보 유형 | 발행 주체 | 토픽 |
|-----------|---------|------|
| 가스 임계값 | 백엔드 서버 | `alerts/{node_id}` |
| 낙상 감지 | 백엔드 서버 | `alerts/wearable-01` |
| O₂ 저하 | 백엔드 서버 | `alerts/wearable-01` |
| 위험 구역 진입 | 백엔드 서버 | `alerts/wearable-01` |
| 연결 끊김 | 백엔드 서버 | `alerts/{node_id}` |

### 10.2 Retain 정책

- `alerts/{node_id}` 토픽은 Retain을 사용한다
- 활성 경보 상태가 유지되어 새 대시보드 연결 시 즉시 표시된다
- 경보 해제 시 `status: "resolved"`로 업데이트한다

### 10.3 지연 목표

| 경보 유형 | P95 목표 | 비고 |
|-----------|---------|------|
| 가스 임계값 | <= 3초 | sampled_at부터 웨어러블 진동까지 |
| 낙상 감지 | <= 3초 | sampled_at부터 대시보드 표시까지 |
| O₂ 저하 | <= 8초 | 센서 응답 시간(15s) 고려, 3초 목표 제외 |
| 위험 구역 진입 | <= 3초 | 위치 업데이트로부터 경보까지 |

> 실험 연결: EXP-4 (End-to-End 경보 지연)

## 11. 진동 패턴

| 위험 등급 | 진동 패턴 | 모터 제어 |
|-----------|-----------|-----------|
| Level 1 (주의) | 0.5초 진동 x 2회 | 짧은 펄스 2회 |
| Level 2 (경고) | 1초 진동 x 3회, 반복 | 1초 펄스 3회 후 2초 대기, 반복 |
| Level 3 (위험) | 연속 진동 | 중단 없이 연속 구동 |

### 하드웨어 제어

```
진동 모터 제어 회로:
  ESP32 GPIO25 -> 1kΩ 베이스 저항 -> S8050 NPN 트랜지스터 -> 진동 모터
  1N4007 다이오드: 모터 양단 병렬 (역기전력 보호)
```

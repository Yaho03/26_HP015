## 1. 시스템 면책 범위

본 시스템은 **작업자 안전을 보조하는 모니터링·경보 도구**이다.

- 최종 대피 판단 및 작업 중지 결정은 현장 관리자에게 있다
- 본 시스템의 경보가 공식 산업안전보건 기준을 대체하지 않는다
- 센서 오차, 통신 지연, 시스템 장애 가능성을 항상 전제해야 한다
- 시스템이 정상 동작하지 않을 경우에도 작업자는 독자적으로 안전을 확보해야 한다

## 1.5 인증과 안전의 트레이드오프 (AUTH — 2026-08-20)

### 결정: 경보 가시성이 세션 관리보다 우선한다

인증을 추가하면 "세션 만료 → 로그인 화면 전환"이 산소결핍·H₂S 같은
L3 경보 발생 순간 **경보 모달과 알림음을 화면에서 지워버릴 수 있다.**
인증 도입이 오히려 시스템을 덜 안전하게 만드는 역설이다.

그래서 다음을 규칙으로 한다:

1. **세션 만료 시 전체 화면 전환 금지** — 로그인은 오버레이로 띄우고,
   경보 배너·모달·알림음은 최상위 레이어에 유지한다 (FR-607).
2. **활성 경보(L2+)가 있는 동안 세션 유휴 타이머를 자동 연장**한다 —
   경보 상황에서 화면이 잠기는 일 자체를 줄인다.
3. WebSocket 인증 거부(close 1008)는 **자동 재연결 금지** — 만료 세션이
   초당 수회 재연결을 시도해 브로커·백엔드를 침몰시키는 것을 막는다.

### 신뢰 경계 전제

- 본 시스템은 **신뢰된 폐쇄망(단말망)** 전제로 설계했다. HTTPS는 리버스
  프록시(nginx)에서 종료하고, 애플리케이션은 오리진 허용 목록으로 제한한다.
- 임계값 무인증 변경(#116 P1-15)은 FR-601~611로 봉쇄했다. 남은 위험:
  폐쇄망 내 단말 탈취 시 쿠키 탈취 — 물리 보안으로만 방어 가능.

### 작업자 개인정보 취급

작업자 명부(이름, 자격번호)와 웨어러블 위치·생체(O₂, 낙상) 데이터는
**안전 목적에 한정**해 처리한다:

- 계정은 웹 UI 사용자(관리자/감독자/열람자)뿐이며, 작업자는 로그인 주체가 아니다.
- 위치 이력은 사고 조사·경보 근거 이외 목적으로 조회하지 않는다.
- 감사 로그(FR-605)에 조회가 아닌 **변경 행위**를 기록해 책임 소재를 남긴다.

## 2. 센서 데이터 신뢰성 제한

### 2.1 BME680

Bosch 공식 사양상 BME680은 온도, 습도, 압력, 공기질 센서이다. BSEC 라이브러리를 통해 IAQ(Indoor Air Quality) 값을 제공한다.

**금지 사항:** 별도 가스 모델과 교정 없이 BME680 출력을 특정 VOC ppm으로 표현하지 않는다.

**권장 출력 필드:**

```json
{
  "gas_resistance_ohm": 84320,
  "iaq_index": 72,
  "iaq_accuracy": 2
}
```

- `iaq_accuracy`가 2 이상일 때만 IAQ 값이 유효하다
- `gas_resistance_ohm`은 경보 판정에 사용하지 않고 추세 모니터링만 수행한다
- `voc_ppm` 필드를 사용하지 않는다

### 2.2 MQ-2 (가연성 가스)

MQ-2 센서 출력을 VOC ppm 또는 LEL%로 직접 표현하는 것은 위험하다.

**필요 사항:**
- 대상 가스 명시
- 센서의 Rs/R0 계산
- 깨끗한 공기에서 R0 교정
- 온습도 영향 보정
- 개별 센서별 보정 계수 적용
- 교정 전 원시값과 계산값 분리

**권장 데이터 모델:**

```json
{
  "raw_adc": 15230,
  "voltage_v": 1.418,
  "rs_ohm": 18500,
  "rs_r0_ratio": 1.12,
  "estimated_concentration": null,
  "calibration_status": "uncalibrated"
}
```

교정 전에는 ppm이나 LEL% 대신 `raw_adc`, `voltage_v`, `rs_r0_ratio`를 표시한다.

### 2.3 MQ-7 / MQ-136 (CO / H2S)

MQ-2와 동일한 교정 원칙을 적용한다.

- 교정 전: `calibration_status: "uncalibrated"`, `estimated_ppm: null`
- 교정 후: `calibration_status: "calibrated"`, `estimated_ppm: <측정값>`
- 교정 전에는 임계값 기반 경보에서 제외한다

### 2.4 SEN0322 (O2)

공식 사양상 응답 시간은 최대 15초 수준이다.

- O2 변화에 대해 "3초 이내 탐지"를 요구하지 않는다
- 전체 경보 3초 목표와 O2 센서 자체 응답 시간을 별도로 관리한다
- O2 데이터 발행 주기는 5초이므로, 급격한 변화 감지에 시간이 소요될 수 있다
- 대시보드에 O2 경보 지연 가능성을 명시한다

## 3. IDW 공간 보간의 한계

### 3.1 IDW는 물리적 가스 확산 모델이 아님

IDW(역거리 가중치 보간법)는 거리 기반 공간 보간 기법이다. 다음 물리적 현상을 반영하지 않는다.

- 환기 방향 및 환기량
- 가스 밀도 (가스 종류에 따른 부력/침강)
- 장애물에 의한 확산 차단
- 열 대류 효과
- 출입구를 통한 기류
- 누출원 방향
- 시간에 따른 가스 이동 (확산 속도)

### 3.2 4개 센서의 한계

4개 센서가 모두 비슷한 높이에 설치되면 사실상 2D 평면 데이터이다. 이를 3D 볼륨으로 렌더링하면 높이 방향의 농도 분포가 실제 측정된 것처럼 보일 수 있다.

### 3.3 화면 레이블 의무

IDW 히트맵 화면에는 다음 레이블을 표시해야 한다.

- **"Estimated concentration surface based on IDW interpolation"**
- 실제 가스 농도 분포가 아닌 센서 측정값 기반 추정 결과임을 명시

### 3.4 경보 사용 금지

- IDW 추정값은 경보 판정에 사용하지 않는다 (ADR-005)
- 경보는 실제 센서 측정값으로만 발생한다
- IDW Heatmap이 빨간색이어도 해당 위치의 실제 센서가 임계값 미만이면 경보 없음
- **누적 노출량 적산에도 사용하지 않는다.** 작업자 위치의 농도는 최근접 센서 노드의 **실측값**을 대입한다. 보간값으로 적산하면 측정된 적 없는 숫자가 적분을 거쳐 "이 사람은 기준의 몇 %를 썼다"는 확정적인 문장으로 바뀐다 — 추정이 근거처럼 보이게 되는 지점이다 (ADR-005/ADR-008, FR-702).

## 3.6 누적 노출량 산출의 한계 (FR-701~708)

`11_EXPOSURE_DOSE_SPEC.md` §7의 요약이다. 화면과 보고서에 함께 명시한다.

### 3.6.1 이것은 법정 측정이 아니라 추정이다

> 본 기능이 산출하는 노출량은 **개인 시료채취(personal sampling)를 통한 법정 작업환경측정을 대체하지 않는다.** 고정 센서 노드의 측정값을 작업자 위치에 대입한 추정값이며, 개인 호흡영역(breathing zone) 측정이 아니다. 최종 작업 중지 판단은 현장 관리자에게 있다.

### 3.6.2 "체내 축적량"이 아니다 — 용어가 곧 안전 문제다

적산은 **흡수·배출 생리 모델이 없는 단순 시간적분**이다. 산출값은 작업자가 **머문 환경의 노출량**이지 몸에 쌓인 양이 아니다.

이 구분을 용어에서 놓치면 시스템이 하지 않는 측정을 했다고 주장하게 된다. 따라서 문서·화면·보고서 어디에서도 **"체내"·"축적"으로 표기하지 않는다.** 프론트엔드 테스트가 면책 문구에 이 두 단어가 들어가지 않는지 검사해 고정한다.

### 3.6.3 근본적 한계

| # | 한계 | 영향 |
|---|------|------|
| 1 | 작업자 위치 농도는 최근접 고정 노드 실측값 대입이다 (ADR-008) | 노드 사이 중간 위치에서 오차. **정량화되지 않았다** |
| 2 | **CO·H₂S는 MQ 센서 미교정으로 산출 불가** | MVP 기간 내내 `unavailable`. 실질 적산은 CO₂ 단독이다 |
| 3 | UWB 측위가 끊기면 최근접 노드를 정할 수 없다 | 적산 **중단** → `data_gap_s` 증가. 추정으로 메우지 않는다 |
| 4 | 개인 호흡영역 측정이 아니다 | 법정 작업환경측정 대체 불가 |
| 5 | 흡수·배출 생리 모델이 없다 | 환경 노출량이지 체내 축적량이 아니다 (3.6.2) |
| 6 | 호흡보호구 착용 여부를 반영하지 않는다 | 보호구 착용 시 실제 노출은 더 낮다 → **과대평가** 방향 |
| 7 | **노출 기준값의 원문 대조 서명이 비어 있다** | 아래 3.6.4 참조 |

한계 #6의 방향은 의도적이다. 과소평가보다 과대평가가 안전한 실패다. 다만 **보고서에서 이 값을 "실제 노출량"으로 제시해서는 안 된다.**

### 3.6.4 기준값 확인 서명 — 미결

`011_exposure_limits.sql`이 CO₂·CO·H₂S 기준값을 시드하고 출처로 고용노동부고시 제2020-48호(2020-01-14) 별표 1을 기록했다. 그러나 **누가 원문을 대조했는지에 대한 서명이 아직 비어 있다** (`EXPOSURE_LIMITS_VERIFICATION.md` §2).

서명이 채워지기 전까지 화면에 표시되는 **소진율(%)을 안전 판단 근거로 제시해서는 안 된다.** 값 자체가 틀렸다는 뜻이 아니라, 이 프로젝트가 "출처 없는 기준값은 기준값이 아니다"(§3.3 MUST)라고 정한 절차가 아직 닫히지 않았다는 뜻이다.

### 3.6.5 화면이 감추면 안 되는 것

- **"측정 없음"을 0%로 그리지 않는다.** 기준값 미시드·측위 상실은 `dose_fraction`이 `null`이다. 0%로 그리면 **판정하지 못한 상태가 안전한 상태로 보인다.**
- **게이지를 100%에서 자르지 않는다.** 상한을 두면 115%와 300%가 같아 보인다.
- **`trust_level`과 `data_gap_s`를 함께 표시한다.** 공백이 크면 dose 자체를 신뢰할 수 없다.
- **노출량 경보는 자동 해제되지 않는다.** 농도가 내려가도 이미 쌓인 노출은 사라지지 않는다. 해제는 노출 윈도우가 닫힐 때뿐이다.

## 4. 복합 위험 점수의 한계

ARCHITECTURE에 정의된 복합 위험 점수의 한계:

| 항목 | 문제 |
|------|------|
| 가중치 0.35/0.30/0.10/0.25 | 검증 근거 없음 |

**결론:** 복합 위험 점수는 실험 검증 전까지 **참고 지표로만 사용**한다. 안전 경보의 단독 근거로 사용하지 않는다.

## 5. 센서 교정 절차

### 5.1 MQ 센서 (MQ-7, MQ-136, MQ-2)

```
1단계: 예열
  - 전원 인가 후 최소 30초 대기 (안정화에는 수 시간 권장)

2단계: R0 측정 (깨끗한 공기 교정)
  - 야외 또는 환기가 잘 되는 청정한 공기 환경에서 측정
  - Rs 측정값을 R0로 저장
  - 센서별로 개별 측정 (동일 모델이라도 편차 존재)

3단계: 온습도 보정
  - BME680 온습도 데이터를 활용하여 Rs 보정
  - 온도 상승 시 Rs 감소 보상

4단계: 대상 가스 교정
  - **MVP에서는 실제 유해 가스 사용 금지로 인해 미수행**
  - 알려진 농도 환경에서 Rs/R0 vs 농도 커브 작성이 필요하나,
    본 프로젝트에서는 실제 가스 사용 불가
  - CO/H2S 경보 파이프라인은 소프트웨어 데이터 주입으로만 검증

5단계: MVP 정책
  - calibration_status: "uncalibrated" 유지
  - estimated_ppm: null 유지
  - raw_adc, voltage_v, rs_ohm, rs_r0_ratio 값만 제공
```

> MQ 센서의 대상 가스 교정에는 알려진 농도의 CO/H2S 가스가 필요하다. 본 프로젝트에서는 안전상 실제 유해 가스를 사용할 수 없으므로, MVP 기간 동안 MQ 센서는 raw 값만 제공하며 경보 대상에서 제외한다. (`06_ALERT_RULES.md` 섹션 4.3 참조)

### 5.2 MH-Z19B (CO2)

- 자동 교정 기능 (ABC, Automatic Baseline Correction) 내장
- 최초 설치 시 야외 공기(~400ppm) 환경에서 24시간 자동 교정 권장
- 수동 교정 (ZERO 캘리브레이션) 기능도 지원

### 5.3 BME680

- BSEC 라이브러리 자동 보정 기능 사용
- 최소 24시간 안정화 필요
- `iaq_accuracy`가 0에서 3으로 자동 승격
- `iaq_accuracy >= 2`일 때 IAQ 값 유효

### 5.4 SEN0322 (O2)

- 출고 시 교정됨
- 주기적 확인 권장: 공기 중에서 20.9% 측정 확인
- 편차가 큰 경우 재교정 필요

### 5.5 DWM1000 BU01 (UWB)

- 안테나 지연 보정 (Antenna Delay Calibration) 필수
- 각 앵커별 송수신 안테나 지연 측정
- 보정 없이는 측위 정확도 보장 불가
- Qorvo 예제 코드의 보정 절차 참조

## 6. 안전한 실험 환경

### 6.1 실제 유해 가스 사용 금지

- 본 프로젝트에서는 실제 유해 가스(CO, H2S 등)를 사용하지 않는다
- 모든 가스 농도 시나리오는 소프트웨어 기반 데이터 주입으로 시뮬레이션한다

### 6.2 데이터 주입 방식

- MQTT 클라이언트를 통해 시나리오 데이터를 publish
- 실제 물리 node_id를 그대로 사용하되 `source_mode: "simulation"` 필드로 실제 센서와 구분
- 주입 데이터는 사전 정의된 시나리오 스크립트 사용
- 주입 데이터의 `quality` 필드에 정상 상태 값을 설정하여 경보 로직 테스트
- 축소 데모 공간의 UWB 좌표를 선박형 3D 트윈에 비율 매핑하는 경우, 화면에는
  `demo-local -> ship-visual` 매핑 상태를 표시한다. 이 좌표는 시연용 투영이며 실제
  선박 내부 실측 좌표로 설명하지 않는다.

### 6.3 진동 모터 안전

- 진동 모터 테스트 시 모터가 과열되지 않도록 연속 구동 시간 제한
- Level 3 (연속 진동) 테스트는 10초 이내로 제한

# 26_HP015 — 스마트해운물류
## IoT센서 시계열 분석 및 3D 디지털 트윈 기반 조선소 밀폐공간 모니터링 시스템

---

## 프로젝트 개요

조선소 밀폐공간 내 유해 가스 농도 및 작업자 상태를 실시간으로 모니터링하는 IoT 시스템.
가스 측정 센서 노드, 서브 센서 노드, 작업자 웨어러블 노드로 구성되며 MQTT를 통해 데이터를 전송한다.

## 하드웨어 구성 요약

| 기기 | 수량 | 메인보드 | 주요 기능 |
|------|------|---------|----------|
| 센서 노드 | 4 | ESP32 DevKitC V4 | CO2/CO/H2S/VOC/온습도 + UWB 앵커 (전 노드 동일 풀스펙) |
| 웨어러블 노드 | 1 | ESP32 DevKitC V4 | 열화상/산소/낙상 감지 + UWB 태그 |

> UWB 위치 측위: 센서 노드 4개(앵커) + 웨어러블 1개(태그)
> 전체 구매 목록 및 핀 연결은 [HARDWARE.md](./HARDWARE.md) 참조
